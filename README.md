## HCMV HOK scRNAseq study 

Raw data available at GSE348416
Manuscript on bioRXiv: https://www.biorxiv.org/content/10.1101/2025.09.16.676604v1

This repository contains codes to process the data and replicate figure2 and figure3
analysis_sample_processing.R: process the data from cellranger output
analysis_soupx_sample_processing.R: sample processing using soupx to remove ambient RNA
analysis_cmv_gene_exp_soupx.R: construct virus gene expression trajectory
